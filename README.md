# 📘 ARIVUM  
### A Web-Based Academic Support System for University Students  

ARIVUM is a centralized academic resource platform designed to help university students access Previous Year Questions (PYQs), important questions, and manage their study workflow efficiently — all in one place.

Built using modern web technologies and Firebase integration, ARIVUM provides secure authentication, personalized dashboards, advanced filtering, and productivity tools.

---

## 🚀 Live Features

- 🔐 Secure User Authentication (Firebase)
- 📚 Previous Year Questions (PYQs)
- ⭐ Important Questions by Subject
- 🎯 Personalized Dashboard
- 📝 To-Do List with Progress Tracking
- 🏫 Filter by University, Course, Semester & Subject
- 📱 Fully Responsive Design
- 💬 Feedback System
- 📢 WhatsApp Channel Integration

---

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3 (Flexbox, Grid, Responsive Design)

### Backend & Database
- Firebase Authentication
- Firebase Firestore (NoSQL Database)
- Firebase Storage

### UI & Styling
- Google Fonts
- Font Awesome Icons

---

## 🧠 Problem It Solves

Students often struggle to:
- Find organized previous year question papers
- Access important questions easily
- Manage study tasks efficiently
- Prepare effectively for exams

ARIVUM centralizes all academic resources and productivity tools into one seamless platform.
